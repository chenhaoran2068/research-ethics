# 干预措施类型“其他”局部复核协议

适用路径：

```text
研究者发起的临床研究
└─ 干预性研究
   └─ 研究设计 → 研究分组信息
      └─ 干预措施类型：其他
```

## 当前 V1 处置

该选项在未保存草稿的正常 UI 抽样中，没有显示初版树预期的
`research-design.other-intervention-type` 输入框；其当前页结构与“物理治疗”代表值一致。

因此该分支标记为 `manual_only_until_local_replay`：

- V1 填写稿不得生成“其他干预措施说明”的可复制内容；
- 用户在平台上选择“其他”后，必须人工核对当前实际显示字段；
- 其他已验证字段可继续生成，但不得把这次抽样解释为后续页完全等价。

## 将来解除方式

仅在新的未保存草稿中，重新选择该根路线、添加一条研究分组，并用正常 UI
完成“其他”与一个常规干预类型的当前页结构对照。若仍存在差异，再只对该节点以下
进行局部 DFS；全程不保存、提交、完成或上传附件。
