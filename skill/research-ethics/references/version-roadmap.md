# 版本路线图

本路线图将“平台规则核验”和“研究计划书模板模块”作为同一版本的两项交付；任何一项未完成，均不得将该路线标记为可自动生成。

| 版本 | 平台路线 | 主要新增的计划书模块 | 进入可用状态的最低验收 |
| --- | --- | --- | --- |
| V1 | 研究者发起 → 观察性研究（诊断试验：是／否） | 观察性研究基础、诊断试验、数据／样本／多中心等条件模块 | 已核验的平台树；中国规则资料层；覆盖矩阵；生成器与回归测试 |
| V2 | 研究者发起 → 干预性研究 | 干预与对照、随机、盲法、分配隐藏、安全性与不良事件 | 独立现场核验；不得复用 V1 的结构结论 |
| V3 | 产品注册 → 药品 | 产品、分期、药物相关设计与安全性模块 | 独立平台树、法规资料和附件核验 |
| V4 | 产品注册 → 医疗器械 | 器械属性；I／II／III 类条件模块 | 三类器械均完成独立差异核验 |
| V5 | 产品注册 → IVD、特医食品 | IVD 与特医食品各自专属模块 | 两条路线分别核验，不能互相推断 |

## V1 的中国通用与双语增强

在不扩大 V1 平台路线的前提下，V1 可以继续增强为“**中国通用、中文主版本＋同源英文配对**”的研究计划书能力：

1. 中国通用骨架不以特定医院模板为前置条件；使用者在正式提交前自行调整本院格式、附件与流程。
2. 结构化研究事实是中文、英文计划书和平台中英文填写项的唯一项目事实源。
3. `public-on-chictr` 路线必须确认平台实际要求的英文配对字段；`private` 路线的英文方案仅在用户需要时生成，不应伪称平台必填。
4. 该增强不改变 V1 仅支持观察性研究的边界，也不使任何尚未现场核验的 V2 路线自动可用。

## 每版共同验收

1. 该路线的平台字段、条件、附件与实时字典边界已按证据等级记录。
2. 该路线的计划书覆盖矩阵标明每一项的来源、适用条件、生成行为和未覆盖原因。
3. 国家／地区规则包、医院补充层与国际质量指南的权威级别明确区分。
4. 模板由结构化规则和代码生成；Word、Markdown 等只是渲染结果，不是另一套事实源。
5. 无法由计划书确定的真实事实仍进入用户确认流程；生成器不编造内容。

## 跨国家与医院的边界

中国大陆规则包是当前唯一实现的国家／地区基线。医院要求应作为可插拔的本地补充层；新国家／地区必须建立新的法律、伦理与登记规则包，不能把中国规则或某医院的要求直接迁移过去。
